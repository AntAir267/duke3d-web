Third-party code compiled into eduke32.wasm / eduke32.js
==========================================================

Besides EDuke32 itself (GNU GPL version 2, see COPYING.TXT) and Ken Silverman's
Build engine (see BUILDLIC.TXT), the engine in this folder contains the code
below. Each keeps its own license; the texts follow the list.
